## Known toolchain breakage (evidence)

Untouched `requirements.txt` installed on Python 3.14, then `python -m pytest`:

```text
File ".../site-packages/_pytest/assertion/rewrite.py", line 962, in visit_Name
    inlocs = ast.Compare(ast.Str(name.id), [ast.In()], [locs])
AttributeError: module 'ast' has no attribute 'Str'
```

`pytest==7.1.2` uses the `ast.Str` alias removed in Python 3.14, so the pinned
dev toolchain cannot run the suite on 3.14 at all. The library code itself is
unaffected (98 passed above with a current runner).
