## v1.1.0 — phases 1–3: geodesy, twilight markers, night divisions

No breaking API changes from 1.0.0. This release completes milestone
phases 1–3 (`docs/development/MILESTONE_PHASES_AND_SLICES.md` slices
1.1–1.7, 2.1–2.8, 3.1–3.4). Phases 4+ (Hijri calendar, moon sighting,
performance/ecosystem) are explicitly out of scope and stay on `main`
for the next minor release.

PyPI: `al-falak==1.1.0` (`import alfalak`). Requires Python `>=3.11`.

### What's new

**Phase 1 — geodesy + calendrical hardening**

- JD/J2000 goldens locked (Meeus Ch.7); Gregorian-only limitation
  documented (no Julian branch — correct for prayer use).
- Qibla bearing locked; `MAKKAH` moved to canonical
  `data/Constants.py` (4-dp `21.4225N, 39.8262E` canonical, 7-dp kept
  for compat); spherical error stated (few arcmin typical, ~0.3–0.35°
  worst); Makkah-to-self/antipode return float in [0,360), no raise.
- New `Qibla.distance_to_makkah_km` (haversine `atan2` form,
  `R = 6371.0088 km` pinned).
- New opt-in `Qibla(method="ellipsoidal")` — Karney inverse on WGS84
  (`astronomy/Geodesy.py`); spherical stays default.

  ```python
  from alfalak import Qibla
  Qibla((3.1390, 101.6869)).direction            # spherical (default)
  Qibla((3.1390, 101.6869), method="ellipsoidal").direction
  Qibla((3.1390, 101.6869)).distance_to_makkah_km
  ```

- New `Qibla.magnetic_direction(declination_deg)` hook
  (`true − declination_east`, NOAA east-positive; lookup stays
  caller-side).

  ```python
  q = Qibla((40.7128, -74.0060))
  q.magnetic_direction(-13.0)  # 13°W example
  ```

**Phase 2 — twilight + prayer markers**

- Twilight preset goldens locked (all 11 + `NONE`).
- New `CalculationMethod.JAKIM` (20/18 — same angles as `SINGAPORE` by
  design; Malay naming + Takwim zone metadata).
- New `imsak` (`Fajr − imsak_offset`, default 10 min, configurable).
- New `syuruk` / `ishraq` / `dhuha` from sunrise (`syuruk == sunrise`;
  `ishraq` +15; `dhuha` window-start +28; `dhuha_offset >=
  ishraq_offset` enforced).

  ```python
  from datetime import datetime
  from alfalak import PrayerTimes, CalculationMethod, Prayer
  pt = PrayerTimes((3.1390, 101.6869), datetime.now(), CalculationMethod.JAKIM)
  print(pt.imsak, pt.syuruk, pt.ishraq, pt.dhuha)
  print(pt.time_for_prayer(Prayer.IMSAK))
  ```

- New `equation_of_time(jd)` / `solar_declination(jd)` wrappers
  (Meeus Ch.28/Ch.25; transit path unchanged).
- New `elevation_m` dip correction (`−0.0293°·√h_m`; sunrise/sunset/
  Maghrib only; default 0 = old behavior).
- New Umm al-Qura Ramadan mode (`is_ramadan=True` → 120 min Isha total
  vs 90; preset-only, not additive +30).

**Phase 3 — night divisions**

- New `first_third_of_the_night`, generic
  `night_fraction(f, start=None, end=None)` (Isha/sunset anchors),
  and `tahajjud_window` (`last_third → next-day Fajr`). Night is
  Maghrib → next-day Fajr; UTC math, minute-rounded.

  ```python
  from alfalak import SunnahTimes
  st = SunnahTimes(pt)
  print(st.first_third_of_the_night, st.middle_of_the_night)
  print(st.last_third_of_the_night, st.tahajjud_window)
  print(st.night_fraction(0.5))
  ```

### Install & upgrade

```bash
pip install al-falak==1.1.0
```

```python
from datetime import datetime
from alfalak import PrayerTimes, CalculationMethod

pt = PrayerTimes((35.7750, -78.6336), datetime.now(), CalculationMethod.NORTH_AMERICA)
print(pt.imsak, pt.fajr, pt.sunrise, pt.syuruk, pt.ishraq, pt.dhuha,
      pt.dhuhr, pt.asr, pt.maghrib, pt.isha)
```

No migration needed from 1.0.0 (additive only). Defaults unchanged:
spherical Qibla, sea-level elevation, non-Ramadan Isha, existing
method angles/offsets.

### Known limitations (deferred, not regressions)

- Magnetic declination is a hook, not a lookup (#55).
- `Coordinates` singleton is mutable — do not mutate `MAKKAH` (#47).
- Method-default precedence + validation deepening pending (#40).
- Hijri/moon-sighting (Yallop/Odeh/MABIMS, UQU/MABIMS calendars,
  sunset-transition, JSON deltas) is phase 4–5, next minor release.
- Cross-port benchmark harness, independent-reference goldens expansion,
  timezone matrix/`fold`, second-precision mode, CLI `--timezone` are
  phase 6, next minor release.
