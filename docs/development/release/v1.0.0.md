## v1.0.0 — first independent `al-falak` release

`al-falak` is versioned independently from `adhanpy` (a separate PyPI
package). This is the first release from the detached fork, originating from
the same `batoulapps/adhan` port lineage as `alphahm/adhanpy`.

`1.0.5` / `1.0.4` entries in `CHANGES.md` are upstream `adhanpy` lineage,
kept for provenance only.

PyPI: `al-falak==1.0.0` (`import alfalak`). Requires Python `>=3.11`.

### Breaking changes — action required

1. **Package renamed: `adhanpy` → `alfalak` (PyPI: `al-falak`)**

   ```bash
   pip install al-falak
   ```

   ```python
   # Before
   from adhanpy import PrayerTimes, CalculationMethod

   # After
   from alfalak import PrayerTimes, CalculationMethod
   ```

2. **Dedicated `AlFalakError` hierarchy replaces builtins.**
   `AstronomicalError`, `ConfigurationError`, `ValidationError` subclass
   `AlFalakError`; messages unchanged. The internal isha-interval
   `ValueError` is untouched.

   ```python
   # Before
   try:
       PrayerTimes(...)
   except RuntimeError:
       ...

   # After
   from alfalak import AstronomicalError

   try:
       PrayerTimes(...)
   except AstronomicalError:
       ...
   ```

   Catch sites to review: polar day/night and undefined Asr now raise
   `AstronomicalError` (with diagnostics, not empty `RuntimeError`);
   unknown madhab raises `ConfigurationError`; non-`CalculationMethod`
   method raises `TypeError` (`None` still means `NONE`).

3. **Python `>=3.11` required** (3.9/3.10 reached end-of-life).
   CI covers 3.11–3.14.

See `docs/user/migration.md` for the full migration guide.

### What's new

- `Qibla` direction calculation, ported from upstream adhan.
- Polar-day/night estimation strategies (`PolarCircleRule`:
  `NEAREST_LATITUDE` by default, `NEAREST_DAY`, `MAKKAH`, `NONE` to keep
  the old raise).
- `SunnahTimes` (middle and last third of the night), ported from
  upstream adhan.
- `PrayerTimes.time_for_prayer(Prayer)` accessor.
- `PrayerTimes` accepts a `Coordinates` object as well as a
  `(latitude, longitude)` tuple.
- `python -m alfalak` CLI printing ISO-8601 UTC markers
  (`alfalak.__main__:main`, scripts `al-falak` / `alfalak`).
- Method parameters copied per instance: mutating one
  `CalculationParameters.method_adjustments` no longer leaks into
  subsequently created instances.
- Input validation: coordinates within [-90, 90]/[-180, 180], angles
  within [0, 90], non-negative Isha interval (plus type hardening —
  see Fixes).
- Typed package: ships `py.typed` (PEP 561), complete annotations,
  `mypy --disallow-untyped-defs` clean with no runtime changes.
- Defined public API surface (`alfalak.__all__` plus `calculation` and
  `data` re-exports).

### Fixes

- Hour-rollover in `rounded_minute` (`10:59:31` now rounds to `11:00`),
  half-up rounding at exactly 30 seconds, microseconds zeroed.
- Asr clamped to Dhuhr when polar-boundary geometry would place it
  earlier, and saturated to Maghrib when shadow-length math spills past
  sunset near the polar boundary (PR #33 + #38; total marker ordering
  now holds everywhere).
- Hardened coordinate validation (PR #38): non-numeric / wrong-arity
  tuples, `bool`, `NaN`/`inf` raise `ValidationError` (not bare
  `TypeError`/`ValueError`) across `PrayerTimes` / `Qibla` /
  `Coordinates`; `Decimal` accepted and normalized to `float`.
- Exact-pole `NEAREST_DAY` documented as unsupported with an actionable
  error (suggests `NEAREST_LATITUDE` / `MAKKAH`) instead of a bare
  year-exhaustion error.
- Narrowed bare `except:` clauses (`Astronomical.corrected_hour_angle`,
  `PrayerTimes._set_isha`).
- Fixed `src/example` header using the wrong date; corrected README CLI
  golden to actual output.

### Tooling / packaging

- Build backend is now hatchling (`setup.py` removed, pinned `==1.32.4`).
- Ruff lint gate (`F`, `E4/E7/E9`) over `src/` and `tests/`;
  `mypy --disallow-untyped-defs` enforced via config.
- Release automation (PR #41): tag `v1.0.0` validated against
  `pyproject.toml`, publishes to PyPI via Trusted Publishing (OIDC) and
  creates the GitHub Release with `dist/*`.
- Supply-chain: `SECURITY.md` policy, zero-runtime-dependencies
  invariant, Dependabot (pip + actions) retargeted to `main`.

### Install

```bash
pip install al-falak==1.0.0
```

```python
from datetime import datetime
from alfalak import PrayerTimes, CalculationMethod

pt = PrayerTimes((35.7750, -78.6336), datetime.now(), CalculationMethod.NORTH_AMERICA)
print(pt.fajr, pt.sunrise, pt.dhuhr, pt.asr, pt.maghrib, pt.isha)
```
